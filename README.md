# Quiz Application 🎯

A simple **Quiz Application** developed using **Python and Tkinter**. This project displays a multiple-choice question with four options and checks the user's selected answer when they click the **Submit** button.

## 📌 Project Overview

The application asks:

**What is the capital of India?**

Users can choose one of four options:
- Chennai
- Mumbai
- Delhi
- Kolkata

After clicking **Submit**, the application displays:
- **Correct** in green when the user selects Delhi.
- **Wrong** in red when the user selects another option.

## ✨ Features

- Simple graphical user interface (GUI)
- Multiple-choice answers using radio buttons
- Submit button to check the selected answer
- Instant feedback with colour-coded results
- Beginner-friendly Python project

## 🛠️ Technologies Used

- **Python** — main programming language
- **Tkinter** — creates the graphical user interface
- **StringVar** — stores the selected answer
- **Functions** — the `check()` function verifies the answer

## ▶️ How to Run the Project

### 1. Install Python

Install Python from [python.org](https://www.python.org/downloads/) if it is not already installed.

Tkinter is included with many standard Python installations. On some Linux systems, it may need to be installed separately.

### 2. Download or Clone the Repository

```bash
git clone <your-repository-url>
```

Open the downloaded project folder.

### 3. Run the Application

Open a terminal in the project folder and run:

```bash
python "quiz applicatiom.py"
```

If your system uses `python3`, run:

```bash
python3 "quiz applicatiom.py"
```
